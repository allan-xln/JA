## Como atualizar

1. Rode o seed contra a base atual:

```bash
docker compose exec api python -m api.scripts.seed_tenants
```

2. Gere novamente este snapshot a partir de `data/demo_users_generated.json`.
3. Confira se nenhum segredo foi incluido antes de commitar.
